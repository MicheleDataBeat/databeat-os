# Credits and rights

DataBeat OS is an unofficial firmware extension by
[DataBeat — Michele Ibba](https://micheledatabeat.github.io/) for the
first-generation Korg volca sample.

## What this repository contains

Documentation only. It contains **no Korg firmware, no DataBeat OS updater or
image and no code**. DataBeat OS is installed with
[VolcaStudio XL](https://micheledatabeat.github.io/volcastudio-xl-releases/),
which builds it on the user's computer from the user's own copy of Korg's
official *volca sample System Updater 1.42*, downloaded from Korg under Korg's
software licence agreement.

## Korg firmware

DataBeat OS is based on Korg's firmware 1.42. Korg retains its rights in the
original firmware and documentation. VolcaStudio XL contains only DataBeat OS's
own changes and applies them to the user's copy; neither this repository nor
VolcaStudio XL distributes Korg firmware.

## Pajen

Credit goes to **Pajen** for his pioneering Volca firmware work. BETA7's bar
filtering, probability, extended-menu workflow and exposure of native reverb
choices informed DataBeat OS's research and design. DataBeat OS uses the Korg
1.42 image, rather than the BETA7 image, as its firmware base. This is not a
claim of clean-room development or a complete authorship audit.

[Pajen's BETA7 announcement](https://www.reddit.com/r/synthesizers/comments/fpxa1c/)
· [BETA7, hosted by Ranzee](https://ranzee.com/volca-sample-unofficial-firmware/).
Ranzee hosts the file; the firmware author is Pajen.
